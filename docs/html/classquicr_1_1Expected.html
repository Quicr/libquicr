Detailed Description

template<typename T, typename E>
class quicr::Expected< T, E >

Holds either a success value or an error value.

Template Parameters
TSuccess type.
EError type.
Note
This class is not internally synchronized. References and pointers returned by accessors are invalidated when the Expected object is destroyed or moved.
Examples
simple_publish/main.cpp, and simple_subscribe/main.cpp.
