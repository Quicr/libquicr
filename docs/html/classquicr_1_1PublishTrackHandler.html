Detailed Description

MOQ track handler for published track.

Publishes one track using unreliable object datagrams (TrackMode::kDatagram) or reliable streams with one stream per subgroup (TrackMode::kStream). Despite older terminology, there are no stream-per-group or stream-per-track modes. Publishing methods and mutable configuration are not internally serialized; callers must not invoke them concurrently.

Publish [full] object.

Encodes and queues one complete object. Datagram mode emits one object datagram. Stream mode creates/reuses the stream identified by (group_id, subgroup_id), emits a subgroup header on first use, and delta-encodes subsequent object IDs. The implementation does not compare data.size() with payload_length; data is the payload that is encoded. A per-object track_mode changes the default mode before encoding subsequent framing, but mode changes while streams are open require application coordination.

Parameters
object_headersObject headers, must include group and object Ids
dataFull complete payload data for the object
stream_modeSubgroup header properties
Returns
Publication result; unsuccessful state checks increment publish_track_metrics_.objects_dropped_not_ok, except a missing request ID.
Exceptions
TransportExceptionif enqueueing fails.
std::bad_optional_accessif required track alias or stream properties were not set.
Note
data is borrowed and copied into an owned queue buffer before return. Calls must be externally serialized.

Reimplemented in quicr::PublishFetchHandler.

◆ publish_track_metrics_

PublishTrackMetrics quicr::PublishTrackHandler::publish_track_metrics_

Publish metrics for the track.

Public live counters updated by publication and session metrics processing. Byte/object counters increase when an object passes state checks, before enqueue success; forwarded bytes increase before the request-ID check. Rejected states increment objects_dropped_not_ok; missing request IDs and later encoding/enqueue failures do not. Counters are cumulative except the QUIC min/max/average aggregates cleared after sampling. Unsynchronized application writes race with library updates.
