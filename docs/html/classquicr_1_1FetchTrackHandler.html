Detailed Description

Handler for receiving a bounded FETCH response.

A fetch uses the subscription object callbacks but requests an inclusive range. Instances are heap-owned through Create() and are retained by the session while active.

Subscribe metrics for the track.

Public live counters updated by receive/session processing. Object counters include decoded data and status datagrams; byte counters count payload bytes for decoded objects and transport stream bytes for streamed delivery. Values are cumulative and are not reset after MetricsSampled. Unsynchronized application writes race with session updates.
