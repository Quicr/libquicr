Detailed Description

template<typename T>
class quicr::SafeQueue< T >

Thread-safe FIFO queue with optional bounded, drop-oldest insertion.

All queue mutations and value access are serialized by an internal mutex. Empty() is a lock-free atomic snapshot and may be stale immediately after it returns. Waiting can be permanently disabled with StopWaiting().

Block waiting for data in queue, then remove the first object from queue (oldest object)

Waits until an element is available or StopWaiting() is called. The predicate is checked while holding the queue mutex, so spurious wakeups do not produce an empty result.
