Detailed Description

Portable wrappers for Clang thread-safety analysis attributes.

When QUICR_HAS_THREAD_SAFETY_ANNOTATIONS is not defined, every macro expands to nothing and has no runtime effect. These annotations describe locking contracts to static analysis; they do not acquire locks themselves.
