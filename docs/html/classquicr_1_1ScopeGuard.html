Detailed Description

template<typename F>
class quicr::ScopeGuard< F >

Non-copyable RAII guard that invokes a callable at scope exit.

Template Parameters
FCallable type, stored by value.
Note
The guard is not thread-safe; synchronize concurrent access to captured state externally.
