Detailed Description

template<typename Type = ParameterType>
class quicr::messages::ParameterList< Type >

Sorted parameter collection with type-directed wire encoding.

The map representation permits only one stored value per numeric key; adding the same type appends to that value rather than creating a second map entry. Consequently, duplicate authorization-token parameters are not represented independently by this class.

Template Parameters
Typeuint64-compatible parameter-key enum or integer type.
