Detailed Description

Server-session callbacks copied when a server is added.

The concurrency, borrowing, reply, and user_data contracts are identical to quicr_session_client_callbacks_t. The same callback table and user_data may be used concurrently by sessions accepted on different transports; synchronize application state accordingly.
