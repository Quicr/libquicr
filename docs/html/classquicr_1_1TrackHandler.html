Detailed Description

Common request state for track-related handlers.

Handlers are intended to be managed by std::shared_ptr; Get() and session registration rely on shared ownership. Request stream access is synchronized, while most other fields are initialized or mutated by the session and are not generally thread-safe.

◆ RequestUpdateReceived()

virtual Reply<messages::Parameters, ErrorCode> quicr::TrackHandler::RequestUpdateReceived ( const messages::Parameters &  params)
pure virtual

Received an update for this handler's request.

The session acknowledges the update with the returned reply: success sends REQUEST_UPDATE_OK with its parameters and failure sends REQUEST_ERROR. Reply::Resolve invokes a deferred producer synchronously, so the producer must start any slow authorization, I/O, or other asynchronous work itself. Completion is queued back through the transport. The request and its stream may disappear before deferred completion, in which case no response is sent.

Parameters
paramsBorrowed updated parameters, valid only for this callback.
Returns
Immediate or deferred acknowledgement.
