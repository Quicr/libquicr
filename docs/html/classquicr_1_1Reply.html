Detailed Description

template<typename T, typename E>
class quicr::Reply< T, E >

The reply to a callback, which may be answered immediately or deferred.

A Reply either holds the callback result or a producer that receives a completion callback. Resolve() invokes a deferred producer synchronously on the calling thread. The producer must start any slow authorization, I/O, or other asynchronous work itself and invoke the completion later.

Template Parameters
TThe value type of a successful reply.
EThe reason code type of a failed reply.

Hand the result to the given continuation, either now or once the deferred action completes.

Immediate continuations run on the calling thread. A deferred completion is queued through transport and runs on the transport notification thread. Capturing the transport keeps it alive until completion is queued.

Template Parameters
FCallable accepting ResultType.
Parameters
transportTransport used to marshal a deferred completion to its notification thread; must remain usable and must not be null.
fContinuation invoked with the result.
Precondition
This reply has not previously been resolved.
Note
Consumes the stored state; resolving the same reply more than once is invalid.
