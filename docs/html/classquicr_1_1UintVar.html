Detailed Description

MoQ variable-length encoding of an unsigned 64-bit integer.

The encoded width is one through nine bytes. Leading one bits in the first byte identify the width; 0xFF introduces the nine-byte form. Construction from an integer produces the shortest encoding, while construction from bytes preserves the encoded width supplied by the caller (including valid non-minimal encodings).
