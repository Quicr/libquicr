Detailed Description

template<KeyType T>
struct quicr::messages::KeyValuePair< T >

MoQ key/value pair.

Keys are delta-encoded relative to the preceding key. Odd keys carry length-prefixed opaque bytes; even keys carry a UintVar represented in value using host-memory byte order and up to eight bytes.
