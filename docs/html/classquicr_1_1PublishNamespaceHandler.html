Detailed Description

Publishes and manages tracks below one namespace prefix.

The handler owns shared references to registered track publishers. Public operations are not internally synchronized and should be serialized with session/application callbacks.

Status codes for the Publish track.

Enumerator
kOk 

Namespace is accepted and active.

kNotConnected 

Session transport is disconnected.

kNotPublished 

Initial/inactive state.

kPendingResponse 

Waiting for the peer's response.

kPublishNotAuthorized 

Peer denied publication.

kSendingDone 

In this state, callbacks will not be called.

kError 

Request failed; inspect GetError().
