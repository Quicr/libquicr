Views a value's in-memory object representation as bytes.

Template Parameters
TA standard-layout type, or std::string.
Parameters
valueValue whose storage is viewed.
Returns
A non-owning span valid until value is destroyed, moved, or otherwise invalidated.

For non-string values the bytes are the native object representation, including native endianness and possible padding; this is not a portable wire encoding. For strings, the span covers the character data only and excludes any null terminator. Mutating value may change the viewed bytes.

◆ FromBytes()

template<class T >
T quicr::FromBytes ( std::span< const uint8_t >  bytes)

Constructs a value from bytes.

Template Parameters
TDestination type.
Parameters
bytesSource bytes.
Returns
A default-initialized T when bytes is empty; a string containing all bytes for std::string; otherwise a zero-initialized T with the supplied bytes copied into the start of its native object representation.
Precondition
For non-string T, bytes.size() <= sizeof(T).
