Detailed Description

template<class Allocator = std::allocator<std::uint8_t>>
class quicr::DataStorage< Allocator >

Shared, segmented byte storage with a flattened bidirectional iterator.

Template Parameters
AllocatorAllocator used by each owned byte-vector slice.

The container and its iterators are not thread-safe. Slices are shared, so retained SliceType instances can outlive their membership in the storage.
