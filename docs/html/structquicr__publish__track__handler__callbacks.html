Detailed Description

Optional callbacks copied at publish-handler creation.

Callbacks may run synchronously on an API caller thread, including while session locks are held, or on a transport notification thread. They may be concurrent across objects or transports. Callback pointer arguments are borrowed for the call. Do not re-enter manager, session, or handler operations on the same objects unless a specific API explicitly permits it. Never destroy a callback-owning object from its callback. Keep user_data valid from creation until successful destruction.
