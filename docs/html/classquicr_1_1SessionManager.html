Detailed Description

Owns transports and sessions and routes generic track handlers to a session.

The manager retains every server session until its connection closes. A client session is likewise retained internally; callers receive a weak reference. Destruction shuts down all transports.

Examples
simple_publish/main.cpp, and simple_subscribe/main.cpp.
