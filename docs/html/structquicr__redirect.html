Detailed Description

Alternate endpoint and track name returned with a redirect rejection.

All fields are borrowed and copied before callback return. A NULL or empty connect_uri reuses the current session URI. A NULL track_namespace and track_name preserve the corresponding parts of the original request. Namespace-scoped requests must leave track_name NULL.
