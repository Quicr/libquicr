◆ tls_cert_filename

std::string quicr::TransportConfig::tls_cert_filename

Path to the external PEM certificate chain used by a server.

The certificate is loaded from this file; certificate material is not stored in this configuration object. Verify its validity period, issuer, signature algorithm, and public-key strength before use.

Examples
simple_publish/main.cpp, and simple_subscribe/main.cpp.
