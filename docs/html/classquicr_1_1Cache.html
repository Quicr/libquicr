Detailed Description

template<typename K, typename T>
class quicr::Cache< K, T >

Time-bucketed ordered cache with shared ownership of stored values.

Template Parameters
KOrdered key type.
TStored value type.

Expiration is lazy: time is advanced by insertion and lookup operations, but not by Size() or Empty(). This class is not thread-safe; externally serialize all access, including calls to const methods.
