Detailed Description

template<typename T, class Allocator = std::allocator<T>>
class quicr::StreamBuffer< T, Allocator >

Contiguous append-only stream accumulator with a logical read offset and parser scratch state.

Template Parameters
TElement type; QUIC variable-length decoding requires a byte-compatible integral type.
AllocatorAllocator for the underlying vector.

Pop operations normally advance a logical offset. A later push compacts consumed storage once the offset reaches the configured threshold or exceeds the unread size. The class is not thread-safe. Spans and references returned by accessors are invalidated by compaction, reallocation, clear, or destruction.

Decodes a variable length array of uint8_t bytes from start of stream buffer

Reads uintV from stream buffer to get the length of the byte array. Then reads byte array from stream buffer after the uintV length. Vector of bytes will be returned if all bytes are available. Otherwise nullopt will be returned to indicate not enough bytes available.

Returns
Returns vector<uint8_t> or nullopt if not enough bytes are available
Note
The length prefix and payload are consumed only when the complete payload is available.
Exceptions
Anyexception thrown while constructing the result vector.

◆ TakeAll()

template<typename T , class Allocator = std::allocator<T>>
BufferT quicr::StreamBuffer< T, Allocator >::TakeAll ( )
inline

Surrender everything not yet read, leaving the buffer empty.

For a caller that takes the whole of what has arrived rather than reading messages out of it one at a time, which costs nothing once it has read what came before. What has been parsed so far is left alone, since that is what says how the stream is being read rather than what is left to read.

Returns
The bytes not yet read

When no prefix has been consumed this may transfer the underlying allocation; otherwise it copies unread elements. Parser scratch state is preserved. All previously returned spans are invalidated.

Exceptions
Anyexception thrown while allocating or copying unread elements.
