std::shared_ptr<Stream> quicr::PublishTrackHandler::StreamInfo::stream

Stream the subgroup is written to.

Held from stream creation until the subgroup ends, so publishing an object costs no lookup. The transport may close the stream underneath this handle, which it detects and rejects on send.
